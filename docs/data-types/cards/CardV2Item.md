# `CardV2Item`

Информация об одной топливной карте договора.

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `id` | `str` | Да | `—` | Уникальный идентификатор карты |
| `group_id` | `str | None` | Нет | `—` | ID группы карт, если назначена |
| `group_name` | `str | None` | Нет | `—` | Название группы карт |
| `contract_id` | `str` | Да | `—` | ID договора, к которому принадлежит карта |
| `contract_name` | `str` | Да | `—` | Название договора |
| `number` | `str` | Да | `—` | Номер топливной карты |
| `status` | `str` | Да | `—` | Системное значение статуса карты |
| `status_name` | `str | None` | Нет | `—` | Отображаемое имя статуса (например 'Активна') |
| `comment` | `str | None` | Нет | `—` | Комментарий, установленный пользователем |
| `product` | `str` | Да | `—` | Тип продукта, например 'limit' или 'wallet' |
| `product_name` | `str | None` | Нет | `—` | Отображаемое имя продукта |
| `carrier` | `str` | Да | `—` | Тип носителя карты ('Plastic' или 'Virtual Card') |
| `carrier_name` | `str | None` | Нет | `—` | Название типа носителя карты |
| `platon` | `bool` | Да | `—` | Признак наличия поддержки Platon (оплата проезда) |
| `avtodor` | `bool` | Да | `—` | Признак наличия поддержки Автодора |
| `sync_group_state` | `str | None` | Нет | `—` | Состояние синхронизации группы карт |
| `users` | `list[str] | None` | Нет | `—` | Список ID пользователей, привязанных к карте |
| `mpc` | `bool | None` | Нет | `—` | Признак наличия мультипроцессингового центра (mpc) |

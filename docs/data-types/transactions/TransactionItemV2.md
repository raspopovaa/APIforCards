# `TransactionItemV2`

Позиция в транзакции (v2).

Для спорных полей здесь сознательно приоритет отдан примерам из спецификации
и реальным ответам DEMO-стенда, а не табличным типам, которые местами
противоречат самим же payload-примерам.

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `id` | `int` | Да | `—` | ID транзакции |
| `timestamp` | `datetime` | Да | `—` | Время транзакции (локальное) |
| `utc_time` | `datetime | None` | Нет | `—` | Время транзакции в UTC |
| `card_id` | `str` | Да | `—` | ID карты |
| `poi_id` | `str` | Да | `—` | ID точки продаж (АЗС) |
| `terminal_id` | `str` | Да | `—` | ID терминала |
| `type` | `str` | Да | `—` | Тип операции (P — покупка, R — возврат) |
| `product_id` | `str` | Да | `—` | ID продукта |
| `product_name` | `str | None` | Нет | `—` | Наименование продукта |
| `product_category_id` | `str` | Да | `—` | Категория продукта (например, НП) |
| `currency` | `str` | Да | `—` | Код валюты (например, RUR) |
| `check_id` | `int` | Да | `—` | Номер чека |
| `stor_transaction_id` | `int` | Да | `—` | ID сторнируемой транзакции |
| `is_storno` | `bool` | Да | `—` | Признак сторно |
| `is_manual_corrention` | `bool` | Да | `—` | Признак ручной корректировки |
| `qty` | `float` | Да | `—` | Количество |
| `price` | `float` | Да | `—` | Цена за единицу |
| `price_no_discount` | `float` | Да | `—` | Цена без скидки |
| `sum` | `float` | Да | `—` | Сумма с учетом скидки |
| `sum_no_discount` | `float` | Да | `—` | Сумма без скидки |
| `discount` | `float` | Да | `—` | Размер скидки |
| `exchange_rate` | `float` | Да | `—` | Курс обмена |
| `card_number` | `str` | Да | `—` | Номер карты |
| `payment_type` | `str` | Да | `—` | Тип оплаты (например, Карта) |

# `PaymentItem`

Информация об одном платеже по договору.

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `id` | `str` | Да | `—` | Идентификатор платежа |
| `contract_id` | `str` | Да | `—` | ID договора, к которому относится платёж |
| `date` | `str` | Да | `—` | Дата и время платежа в формате ISO 8601 (например, 2015-04-15T15:25:20) |
| `amount` | `str` | Да | `—` | Сумма платежа в валюте договора |
| `currency` | `str` | Да | `—` | Код валюты и её обозначение, например '810;RUR' |
| `amount_client` | `str` | Да | `—` | Сумма, поступившая клиенту |
| `description` | `str` | Да | `—` | Описание или назначение платежа |
| `payment_name` | `str` | Да | `—` | Наименование типа платежа, например 'Payment To Client Contract' |
| `payment_type` | `str` | Да | `—` | Тип платежа, например 'P;Advice' |
| `payment_number` | `str` | Да | `—` | Номер платёжного документа |

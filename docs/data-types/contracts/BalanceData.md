# `BalanceData`

Данные по расходу и балансу договора

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `available_amount` | `str` | Да | `—` | Доступный остаток |
| `own_balance` | `str` | Да | `—` | Собственные средства |
| `balance` | `str` | Да | `—` | Собственные средства клиента с учетом блокировок |
| `consumption_for_month` | `str` | Да | `—` | Расход в текущем месяце (в валюте контракта) |
| `consumption_for_month_volume` | `str` | Да | `—` | Объем потребления в текущем месяце (в литрах) |
| `consumption_for_prev_month_volume` | `str` | Да | `—` | Объем потребления в предыдущем месяце (в литрах) |
| `last_payment_sum` | `str | None` | Нет | `—` | Сумма последнего платежа |
| `last_payment_date` | `str | None` | Нет | `—` | Дата последнего платежа |
| `currency` | `str` | Да | `—` | Валюта договора |

# `InvoiceItem`

Информация об одном счёте на оплату.

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `id` | `str` | Да | `—` | Уникальный идентификатор счёта |
| `contract_id` | `str` | Да | `—` | ID договора, к которому относится счёт |
| `ref_number` | `str` | Да | `—` | Номер счёта, указанный в системе |
| `date_start` | `str` | Да | `—` | Дата начала периода счёта (YYYY-MM-DD) |
| `date_end` | `str` | Да | `—` | Дата окончания периода счёта (YYYY-MM-DD) |
| `last_update` | `str` | Да | `—` | Дата и время последнего обновления счёта (ISO формат) |
| `currency` | `str` | Да | `—` | Код валюты, например '810' |
| `amount` | `str` | Да | `—` | Сумма счёта |
| `paid_amount` | `str` | Да | `—` | Оплаченная сумма |
| `status` | `str` | Да | `—` | Статус счёта, например 'OPEN' или 'PAID' |
| `comment` | `str` | Да | `—` | Комментарий к счёту, например 'Intermediate Invoice' |

# `PaymentsData`

Секция data из ответа API, содержит список платежей и их количество.

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `total_count` | `int` | Да | `—` | Количество найденных платежей |
| `result` | `list[PaymentItem]` | Да | `—` | Список платежей по договору |

# `DocumentItem`

Информация об одном первичном документе.

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `id` | `str` | Да | `—` | Уникальный идентификатор документа (UUID) |
| `name` | `str` | Да | `—` | Название документа, например 'УПД' |
| `name_doc` | `str` | Да | `—` | Системное имя документа, например 'СчетФактураВыданный' |
| `number` | `str` | Да | `—` | Номер документа, например 'CSC0000000533998' |
| `date` | `int` | Да | `—` | Дата документа в формате UNIX timestamp |
| `total` | `float` | Да | `—` | Общая сумма документа |
| `vat` | `float` | Да | `—` | Сумма НДС |
| `sum` | `float` | Да | `—` | Сумма без НДС |
| `currency` | `str` | Да | `—` | Валюта документа, например 'руб.' |
| `consignee` | `str` | Да | `—` | Грузополучатель (организация) |
| `contract_id` | `str` | Да | `—` | ID договора, к которому относится документ |
| `contract_name` | `str` | Да | `—` | Номер или название договора |

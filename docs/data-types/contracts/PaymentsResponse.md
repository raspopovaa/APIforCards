# `PaymentsResponse`

Основная модель ответа метода /getPayments.

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `status` | `dict[str, Any]` | Да | `—` | Объект с кодом статуса ответа сервера, например {'code': 200} |
| `data` | `PaymentsData` | Да | `—` | Основная часть ответа с данными о платежах |
| `timestamp` | `int` | Да | `—` | Метка времени ответа сервера в формате Unix timestamp |

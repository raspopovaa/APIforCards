# `InviteCard`

Информация о карте, привязанной к приглашению

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `sid` | `str` | Да | `—` | ID карты (SID) |
| `number` | `str` | Да | `—` | Номер карты |
| `product` | `str` | Да | `—` | Тип продукта ('wallet' и т.п.) |
| `comment` | `str | None` | Нет | `—` | Комментарий к карте (например, имя водителя) |
| `status` | `str | None` | Нет | `—` | Технический статус карты |
| `status_name` | `str | None` | Нет | `—` | Отображаемое название статуса |
| `contract_id` | `str | None` | Нет | `—` | ID договора, к которому относится карта |
| `contract_name` | `str | None` | Нет | `—` | Номер договора |

# `InviteActionResult`

Результат действий с приглашениями (создание, продление, повторная отправка)

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `id` | `str` | Да | `—` | ID приглашения |
| `url` | `str` | Да | `—` | Ссылка на приглашение |
| `attempts` | `int | None` | Нет | `—` | Количество попыток отправки |
| `expired_at` | `int | None` | Нет | `—` | Дата истечения срока действия ссылки (timestamp) |

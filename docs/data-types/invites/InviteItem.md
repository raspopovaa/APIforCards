# `InviteItem`

Элемент списка приглашений

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `id` | `str` | Да | `—` | ID приглашения |
| `user_id` | `str | None` | Нет | `—` | ID пользователя, если уже создан |
| `url` | `str` | Да | `—` | Ссылка на регистрацию (уникальная, активна 3 дня) |
| `status` | `str` | Да | `—` | Технический статус приглашения (Active, Finished и т.п.) |
| `status_name` | `str` | Да | `—` | Отображаемое название статуса |
| `role` | `str` | Да | `—` | Роль пользователя ('Driver', 'Admin' и т.п.) |
| `role_name` | `str` | Да | `—` | Название роли |
| `attempts` | `int | None` | Нет | `—` | Количество отправок приглашения |
| `cards` | `list[InviteCard] | None` | Нет | `—` | Список карт, связанных с приглашением |
| `initiator` | `str | None` | Нет | `—` | Пользователь, создавший приглашение |
| `contracts` | `list[InviteContract] | None` | Нет | `—` | Список договоров, привязанных к приглашению |
| `mobile` | `str | None` | Нет | `—` | Номер телефона приглашенного |
| `email` | `str | None` | Нет | `—` | Email приглашенного |
| `communication_type` | `str | None` | Нет | `—` | Тип отправки ('sms', 'email' и т.п.) |
| `sended_at` | `int | None` | Нет | `—` | Время отправки (timestamp) |
| `expired_at` | `int | None` | Нет | `—` | Время истечения срока действия ссылки (timestamp) |

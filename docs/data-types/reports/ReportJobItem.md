# `ReportJobItem`

Элемент списка заказанных отчетов.

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `date` | `str` | Да | `—` | Дата создания заказа отчета |
| `client_id` | `str | None` | Нет | `—` | ID клиента |
| `user_id` | `str | None` | Нет | `—` | ID пользователя |
| `contract_id` | `str | None` | Нет | `—` | ID договора |
| `contract_name` | `str | None` | Нет | `—` | Название договора |
| `job_id` | `str` | Да | `—` | Идентификатор задания (Job ID) |
| `report_name` | `str` | Да | `—` | Название отчета |
| `report_format` | `str` | Да | `—` | Формат отчета (pdf, xlsx и т.д.) |
| `available_after` | `int | None` | Нет | `—` | Количество секунд до доступности отчета |

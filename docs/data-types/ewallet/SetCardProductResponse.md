# `SetCardProductResponse`

Ответ на запрос изменения типа продукта карты (setCardProduct).
Пример ответа:
{
    "status": {"code": 200},
    "data": ["11148025"],
    "timestamp": 1596024392
}

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `status` | `Status` | Да | `—` | Статус выполнения операции. |
| `data` | `list[str]` | Да | `—` | Список идентификаторов карт, у которых изменён продукт. |
| `timestamp` | `int` | Да | `—` | Метка времени ответа (UNIX timestamp). |

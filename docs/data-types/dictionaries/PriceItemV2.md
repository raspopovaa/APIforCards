# `PriceItemV2`

Информация о цене товара на торговой точке

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `ID` | `str | None` | Нет | `—` | Идентификатор цены |
| `GasStationID` | `str | None` | Нет | `—` | ID торговой точки (АЗС) |
| `GoodsCode` | `str | None` | Нет | `—` | Код товара (из справочника GoodsCode) |
| `Price` | `str | None` | Нет | `—` | Цена товара |
| `Currency` | `str | None` | Нет | `—` | Код валюты, например '810;RUR' |
| `DateTo` | `str | None` | Нет | `—` | Дата действия цены до |
| `DateFrom` | `str | None` | Нет | `—` | Дата начала действия цены |
| `hex_color` | `str | None` | Нет | `—` | HEX-код цвета товара (если указан) |
| `name` | `str | None` | Нет | `—` | Название товара |
| `CurrencyName` | `str | None` | Нет | `—` | Наименование валюты |
| `sort` | `int | None` | Нет | `—` | Порядковый номер отображения |

# `DictionaryItem`

Элемент справочника (универсальная модель)

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `id` | `str` | Да | `—` | Уникальный идентификатор элемента справочника |
| `code` | `str | None` | Нет | `—` | Код элемента (например, код валюты) |
| `value` | `str | None` | Нет | `—` | Значение элемента (используется в старых справочниках) |
| `name` | `str | None` | Нет | `—` | Название элемента (используется в новых справочниках) |
| `deleted` | `int | None` | Нет | `—` | Признак удаления элемента (0 — активен) |
| `last_update` | `str | None` | Нет | `—` | Дата последнего обновления записи |

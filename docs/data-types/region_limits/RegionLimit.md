# `RegionLimit`

Региональный лимит по договору, карте или группе карт.

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `id` | `str | None` | Да | `—` | ID регионального лимита |
| `contract_id` | `str` | Да | `—` | ID договора, к которому относится лимит |
| `card_id` | `str | None` | Нет | `—` | ID карты, если лимит задан для карты |
| `group_id` | `str | None` | Нет | `—` | ID группы карт, если лимит задан для группы |
| `country` | `str` | Да | `—` | Код страны обслуживания, пример - RUS |
| `region` | `str | None` | Нет | `—` | Код регион обслуживания |
| `service_center` | `str | None` | Нет | `—` | ID АЗС |
| `date` | `str | None` | Нет | `—` | Дата последнего изменения |
| `limit_type` | `int` | Да | `—` | Тип лимита |

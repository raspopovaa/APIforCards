# `LimitItem`

Продуктовый лимит (карта, группа или договор).

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `id` | `str | None` | Нет | `—` | ID лимита (для изменения — обязателен) |
| `card_id` | `str | None` | Нет | `—` | ID карты, если лимит задан для карты |
| `group_id` | `str | None` | Нет | `—` | ID группы карт, если лимит задан для группы |
| `contract_id` | `str` | Да | `—` | ID договора, к которому относится лимит |
| `productGroup` | `str | None` | Нет | `—` | ID группы продуктов |
| `productType` | `str | None` | Нет | `—` | ID типа продукта |
| `amount` | `LimitAmount | None` | Нет | `—` | Ограничение по объёму (литры и т.д.) |
| `sum` | `LimitSum | None` | Нет | `—` | Ограничение по сумме в валюте договора |
| `term` | `LimitTerm | None` | Нет | `—` | Периодичность и временные ограничения |
| `transactions` | `LimitTransactions | None` | Нет | `—` | Ограничения по количеству транзакций |
| `time` | `LimitTime | None` | Нет | `—` | Периодичность сброса лимита |
| `date` | `str | None` | Нет | `—` | Дата создания лимита (формат dd/mm/yyyy hh:mm:ss) |

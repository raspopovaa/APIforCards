# `RestrictionSetResponse`

Ответ на установку или изменение ограничителя (POST /setRestriction).

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `data` | `list[str]` | Да | `—` | Список ID созданных или изменённых ограничителей |
| `timestamp` | `int` | Да | `—` | Временная метка ответа (Unix time) |

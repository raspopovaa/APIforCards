# `RestrictionItem`

Модель одного товарного ограничителя (ограничение по продукту).

| Поле | Python-тип | Обязательное | Alias | Описание |
|---|---|:---:|---|---|
| `id` | `str` | Да | `—` | ID ограничителя |
| `card_id` | `str | None` | Нет | `—` | ID карты, если ограничитель задан для карты |
| `group_id` | `str | None` | Нет | `—` | ID группы карт, если ограничитель задан для группы |
| `contract_id` | `str` | Да | `—` | ID договора |
| `productType` | `str | None` | Нет | `—` | ID типа продукта (например, '1-CK231') |
| `productGroup` | `str | None` | Нет | `—` | ID группы продуктов (если применимо) |
| `productTypeName` | `str | None` | Нет | `—` | Название типа продукта |
| `productGroupName` | `str | None` | Нет | `—` | Название группы продуктов |
| `restriction_type` | `int` | Да | `—` | Тип ограничения (1 – Разрешающий ограничитель, 2 – Запрещающий ограничитель) |
| `date` | `str | None` | Нет | `—` | Дата установки ограничителя (в формате MM/DD/YYYY HH:mm:ss) |
